Files associated with the publication "Gravity Modelling of Ice Thickness and Valley Geometry on Taku Glacier (T'aakú Kwáan Sít'i), Alaska".

Jupyter notebooks, model components and required packages gives the code and data required to run the data analysis.

Results contains the results from each of the simple-shape inversions and the manual fit models. All coordinates are in UTM 8N. 
Dist points gives the along flow thickness profile with means refering to the ice thickness and sds refering to the associated uncertainty
Final thick gives a tif file of the 3D thickness model from the simple shape inversion.
Within manual results folders there is the final model in tif form and the results along each of profile 4 and 7a. 'man_2km_t' is the ice thickness. 'man_2km_g' is the gravity calculated along the profile for the model.
